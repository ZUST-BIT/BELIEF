# run the code
To run the code, follow the steps below:
1. Clone the repository
``` git clone https://github.com/ZUST-BIT/MEDAR-QA.git ```
2. Install the required packages
``` pip install -r requirements.txt ```
3. Run the code
``` python run.py ```
